핵심 개념 넷

01 · ASYNC

왜 백그라운드인가

AI 분석은 수 초~수십 초. 그런데 Slack은 3초 안에 응답을 기대한다. 그래서 즉시 ack하고 뒤에서 처리하는 것이 선택이 아니라 필수다.

02 · STATELESS

DB 없는 무상태

버튼이 눌렸을 때 필요한 PR 정보를 HMAC 서명 토큰(24h 만료)에 담아 버튼 value로 전달한다. 서버는 아무 상태도 저장하지 않는다.

03 · SECURITY

3중 검증

GitHub 서명 · Slack 서명 + 리플레이 방지 · action token 서명·만료 · 승인자 허용목록. 모든 진입 경로를 상수시간 비교로 검증한다.

04 · COST

AI 비용 캡

호출 전 count_tokens로 크기를 재고, 예산을 넘으면 큰 파일은 diff-only로 강등한다. 무엇을 뺐는지 로그로 남긴다(조용한 truncation 금지).

### 설치 (Windows)

Windows에서 `python`이 **Microsoft Store 별칭 리다이렉터**(`WindowsApps\python.exe`)에 걸려 "Python was not found"가 뜨는 경우가 많다. 실제 Python을 설치해 PATH에 올린다:

```powershell
# winget (권장)
winget install --id Python.Python.3.11 -e

# 설치 후 새 터미널에서 확인 (py 런처가 가장 신뢰도 높음)
py --version
python --version
```

> **Store 별칭 끄기(선택)**: 설정 → 앱 → 고급 앱 설정 → 앱 실행 별칭에서 `python.exe` / `python3.exe`를 끄면 리다이렉터가 실제 Python을 가리지 않는다.

WHAT CHANGED

## 0. 사전 요구사항 — Python (필수)

이 플러그인의 **실행 로거·대시보드 리포트 hook**은 Python으로 동작한다. Python이 PATH에 없으면 hook이 매 툴 호출마다 다음과 같이 실패하고, **실행 로그·대시보드가 생성되지 않는다**(파이프라인 본체는 non-blocking으로 계속 진행되지만 히스토리가 남지 않음):

```
PreToolUse:Bash hook error
```
